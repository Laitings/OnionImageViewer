# ARRI LUTs

ARRI's own LogC3 and LogC4 to Rec.709 (Gamma 2.4, D65) LUTs, 33-point, from ARRI's v1 LUT
packages (downloadable from arri.com).
The files are ARRI's, unchanged. The build copies them to `luts/` next to the .exe, where the
"ARRI LogC3/LogC4 → Rec.709" views use them instead of the built-in approximations.
